# Writing logic: Preliminaries

- What to write: The problem definition, giving the inputs, the outputs and the setting; the background knowledge and notation used later; any existing framework the paper builds on, with the input and output of each of its steps.
- Check: Every symbol used later is defined here or where it first appears. Everything borrowed from others is fully introduced here, so that the method section only covers what is new. Core concepts the paper proposes are defined at the start of the first component that uses them, not here.
