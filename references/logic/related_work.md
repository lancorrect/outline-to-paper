# Writing logic: Related work

The chain is simple: each subsection first introduces related work, and its last paragraph, the discussion, points out the gap. Which works each subsection covers, and in how much detail, is decided case by case; this skill does not prescribe it.

- Check:
  - Every subsection ends with a discussion, and the gap it points out connects to the general problem or the challenges of the introduction.
  - The description of prior methods agrees with the introduction.
