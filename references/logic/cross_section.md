# Writing logic: Correspondences across sections

Check these once more, separately, during the final check.

| Correspondence | Where | Check |
|---|---|---|
| General problem | Abstract, introduction, discussions of the related work, conclusion | The same problem throughout |
| Challenges, components, contributions | Abstract, introduction, contribution list | Same number and order |
| Components and experiments | Method section, RQs of the experiments | Every RQ is answered by an experiment and maps to a component; the RQs may follow the order of the method section rather than the introduction |
| How the components are described | Abstract, method paragraph of the introduction, contributions, method section, caption of the overview figure, conclusion | Names and key actions are described consistently |
| Results | Abstract, experiment item of the contributions, experiments, conclusion | Same strength, same numbers |
| Core concepts | Whole paper | Every core concept used is defined somewhere |
| Description of prior work | Introduction, related work | No contradictions |
| Conclusions of figure captions | Captions, outline | They go no further than the conclusions written in the outline |
